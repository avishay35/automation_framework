# automation_framework
A test automation framework for conduit demo apoplication
An open-source, production-grade Test Automation & DevOps Framework on my GitHub to showcase senior-level engineering capabilities (Python, Playwright, Pytest, Docker, CI/CD).### Technical Context & Stack* Target Application: Conduit (RealWorld App - https://demo.realworld.show/) — a modern Single Page Application (SPA) with a full RESTful JSON API on the same domain.* API Spec Reference: OpenAPI spec at https://realworld-docs.netlify.app/docs/specs/backend-specs/endpoints* Tech Stack: Python 3.11+, Pytest, Playwright (`pytest-playwright`), HTTPX/Requests (API client), Pydantic v2 (Schema validation), Docker, GitHub Actions, Allure / HTML reporting.### Key Architectural Principles1. Modern Page Object Model (POM): Locators placed directly inside Page classes using Playwright's user-facing locators (`get_by_role`, `get_by_placeholder`, `get_by_test_id`). No external JSON/DB locator files.2. Fast Session Injection: Bypass slow UI logins for UI tests by obtaining a JWT token via API (`POST /api/users/login`) and injecting it directly into Playwright's browser context.3. 100% Test Independence: Tests are fully isolated, stateless, and safe for parallel execution using `pytest-xdist`.4. Robustness & SLA: Strict Schema validation with Pydantic v2, API retry mechanisms (`tenacity`/`urllib3`), and zero static `time.sleep()` calls.5. Network Interception & Fault Injection: Playwright route mocking (`page.route()`) to simulate 500 errors and edge cases.6. Containerization & CI/CD: Dockerized execution grid running via GitHub Actions (`.github/workflows/ci.yml`) with automated test report artifacts
